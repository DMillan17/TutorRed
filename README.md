# TutorRed - Plataforma de Gestion de Tutorias con IA

Proyecto formativo SENA - ADSO
Plataforma web responsiva para gestión de tutorías académicas con integración de IA RAG para repositorio de recursos.

## 🚀 Stack Tecnológico
- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Backend:** NestJS + TypeScript
- **IA Service:** Python + FastAPI + LangChain (RAG)
- **Base de Datos:** PostgreSQL / Supabase
- **Control de Versiones:** Git + GitHub (GitFlow)

## 👥 Equipo - 5 Integrantes
| Rol | Responsabilidad | Carpeta |
|---|---|---|
| I1 - Backend / BD | Arquitectura y BD | `database/`, `backend/src/modules/auth` |
| I2 - Frontend | UI Responsiva | `frontend/` |
| I3 - IA / RAG | Repositorio y Asistente | `ai-service/` |
| I4 - Lógica Tutorías | Gestión de tutorías | `backend/src/modules/tutorias` |
| I5 - QA / Docs | Pruebas y Docs | `tests/`, `docs/` |
